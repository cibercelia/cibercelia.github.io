¿Cómo colaborar en CiberCelia?

El alumnado puede publicar artículos técnicos, enlaces de interés o noticias mediante solicitudes de extracción (*pull requests*) en GitHub.

01

Haz un fork del repositorio

Bifurca el repositorio en tu cuenta de GitHub y clónalo en tu equipo.

git clone https://github.com/TU_USUARIO/cibercelia.git
02

Añade tu contenido en Markdown

Crea tu archivo .md en content/posts/ con metadatos de autor.

content/posts/mi-nuevo-articulo.md
03

Abre una pull request

Sube tus cambios en una rama y abre un PR en cibercelia para revisión.

git push origin mi-nuevo-articulo
