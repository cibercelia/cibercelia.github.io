¿Cómo publicar en CiberCelia?

Todo el alumnado del Curso de Especialización de Ciberseguridad del IES Celia Viñas puede publicar artículos, noticias o recursos mediante Pull Requests en GitHub.

01

Haz Fork del repositorio

Bifurca el repositorio oficial en tu cuenta de GitHub y clónalo en tu entorno local.

git clone https://github.com/TU_USUARIO/cibercelia.git
02

Añade tu contenido Markdown

Crea tu archivo .md en content/posts/ con metadatos de autor y etiquetas.

cp content/posts/01-plantilla.md content/posts/mi-post.md
03

Abre una Pull Request

Sube tus cambios a una nueva rama y abre un PR en la organización cibercelia para revisión.

git push origin mi-nuevo-articulo
